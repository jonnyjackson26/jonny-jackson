Official mobile app for the n^ Boost Conference, hosted by [Nucleus](https://www.nucleusutah.org/).

[View showcase on Youtube](https://www.youtube.com/shorts/VjbMXkzDzpo)
{{<youtube VjbMXkzDzpo>}}

### Features
- Swig drink ordering  
- Full event schedule access  
- Mentor discovery  
- In-app messaging  
- Session booking  

### Tech Stack
- React Native (Expo)  
- Authentication: Google OAuth, Apple OAuth, Email/Password  
- Supabase 

### Roles & Permissions

**Admins**
- Send push notifications to all attendees  
- Manage and edit the event schedule  

**Mentors**
- Set and update availability  
- Manage session bookings  

**Participants**
- Browse and discover mentors  
- Book sessions  
- Message mentors in-app
